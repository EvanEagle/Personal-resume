# Personal Portfolio

個人履歷與作品集網站，用來展示我的技術能力、專案經驗與職涯經歷。

目前主要以 Java 後端開發為學習與求職方向，並透過實際製作本網站，練習 HTML、CSS、JavaScript、Git 與 GitHub Pages 部署流程。

## About This Project

這個 Portfolio 主要整合以下內容：

- 個人簡介
- Java 後端相關技能
- 專案作品展示
- 工作與學習經歷
- GitHub 聯絡資訊
- Email 一鍵複製功能
- RWD 響應式網頁設計

網站採用簡潔、清新的米色系設計，並針對桌面與行動裝置進行版面調整。
